Tích hợp AI Security Bot vào GitHub Repository

Cách 1: Sử dụng GitHub Actions (Dễ nhất - Không cần server)

Tạo file .github/workflows/security-bot.yml trong kho lưu trữ của bạn:

name: AI Security Code Review
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  security-review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run AI Security Reviewer
        uses: dtc245200494-hue/Automated_Code_Reviewer@v1
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
          LANGUAGE: "Tiếng Việt"

Cách 2: Triển khai dưới dạng Webhook Bot

Cấu hình Webhook trong GitHub App trỏ về endpoint của bạn: https://your-domain.com/api/github/webhooks
